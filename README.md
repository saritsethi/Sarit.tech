# sarit.tech | The AI Product Leader’s Digital HQ 🏗️🤖

**A high-performance, ROI-focused personal storefront bridging a decade of construction technology leadership with the frontier of Generative AI.**

---

## 🎯 The Product Vision
Most personal sites are static resumes. **sarit.tech** is a functional prototype of a "Digital Twin" experience. It acts as a 24/7 executive screener, providing direct access to my professional frameworks, enterprise AI strategy, and personal journey through a grounded **RAG (Retrieval-Augmented Generation)** interface.

## 🛠️ The Tech Stack (Zero-Cost Infrastructure)
As a Product Director, I believe in maximizing output while minimizing operational overhead. This site runs on a **$0/mo** stack (excluding domain):

| Component | Technology | Purpose |
| :--- | :--- | :--- |
| **Frontend** | Next.js 14 (App Router) + Tailwind CSS | Speed, SEO, and "Industrial Minimalist" UI. |
| **The Brain** | Gemini 3.1 Pro API + File Search | Managed RAG for the "Digital Twin" chatbot. |
| **The Bones** | Sanity.io (Headless CMS) | Structured data management for all static content. |
| **The Blood** | Substack RSS | Dynamic thought leadership feed (CODO Strategy). |
| **The Eyes** | PostHog | User journey tracking and chatbot intent analysis. |
| **Deployment** | Replit + GitHub | CI/CD pipeline for rapid iteration. |

## ✨ Key Features

### 🧠 The "Sarit" Digital Twin (Custom RAG)
A command-line style interface grounded in my actual career data (Resume, Manifestos, Substack articles). Unlike a generic LLM, this bot understands my specific take on:
* **Construction SaaS & Engineering Workflows**
* **AI Governance & Alignment** (The Sarth(A)i Philosophy)
* **The ROI of Product Investment**
* **High-Performance Cricket Equipment** (Grade 1 English Willow specs)

### 🏗️ The Hybrid CMS Strategy
I leverage **Substack** for distribution (The Spokes) and **Sanity** for architecture (The Hub). This ensures the site remains a living asset without requiring manual code updates for every new post.

### 📈 ROI-Driven Analytics
Integrated with **PostHog** to track conversion funnels: from landing on "The Builder" section to a confirmed booking on my **Google Appointment Calendar**.
